Common questions

Should I install a radon system before I have a test number?

No. Test first. Mitigation is the next decision after you have a reading.

What number means I should mitigate?

The EPA action level is 4.0 pCi/L. Ask the shop to write your reading and units. Some owners choose a lower target in writing.

Why do quotes differ so much?

One shop prices a single fan. Another adds crawl encapsulation or a second suction point. Ask what is included if the first system does not drop the reading.

Who pays for the test after the fan is in?

Ask before you sign. Some shops include a post-mitigation test. Some charge extra.
