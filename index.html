High radon scare. Test first. Mitigate only if the number is at or above 4.0.

Phoenix buyers and sellers mix a $150 test with a multi-thousand-dollar fan. Quotes jump when a shop adds crawl encapsulation or a second system after the first one misses the target. Use this list before you book.

  • Get a written test result with units (pCi/L) before you buy a system.
  • Compare that number to the EPA action level of 4.0 pCi/L.
  • Ask whether the quote is one system or includes crawl / addition work as extras.
  • Ask who pays the post-mitigation retest and what number they guarantee.
  • Call a shop that publishes a phone on its own website.
